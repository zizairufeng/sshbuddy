## 一、修复的问题

### 1. RDP 键盘一输入就断线（高优先级）

**根因**：FreeRDP 3.x 的命令行解析器默认把 `FreeRDP_UnicodeInput` 设为 `FALSE`，
应用此前没有传 `/kbd:unicode`。JNI 侧 `android_process_event()` 又把“发送 Unicode 失败”
当成致命错误，直接跳出事件循环并回调 `OnConnectionFailure`，表现就是敲键盘即断线。

**修复**（`rdp/RdpSession.kt`）：

- 连接参数新增 `/kbd:unicode`，服务端支持时走 Unicode 输入；
- 发送前仍用 `freerdp_is_unicode_input_supported()` 判断，不支持时回退到
  “Shift + 虚拟键码”，不会再把失败上报成连接失败；
- 补充 Tab 键与代理对（emoji 等增补平面字符）的发送；
- 新增 `/bpp:32`、`/client-hostname:SSHBuddy`、`/network:auto`，改善画质和弱网表现。

### 2. RDP 断开时可能 use-after-free（高优先级）

原实现在 `disconnect()` 后固定等 2 秒就调用 `freeInstance()`。如果 native 工作线程
未及时退出，`freerdp_free` 会访问已释放内存。现改为（`rdp/RdpSession.kt`）：

- 已连接过的会话最多等 10 秒；
- 从未连上的会话等 1.5 秒；
- 超时则**跳过** `freeInstance`（少量泄漏优于崩溃），并写 warning 日志。

### 3. 触控模式长按后误触发左键拖拽（中优先级）

长按已经发送了右键，手指继续移动时原逻辑仍会 `beginLeftDragAt()`，导致远端出现
“右键菜单刚弹出又被左键拖走”。已在 `ui/RdpSurfaceView.kt` 用 `longPressFired` 拦截。

### 4. Windows 登录界面无法操作（易用性）

新增 `sendCtrlAltDel()`（`rdp/RdpSession.kt`），RDP 工具栏菜单新增
“Ctrl+Alt+Del” 项（`ui/RdpScreen.kt`、`RdpActivity.kt`）。锁屏/登录界面必需。

### 5. 手机剪贴板无法发到 Windows（易用性）

RDP 菜单新增“发送剪贴板到 Windows”，通过 `sendClipboard()` 发送文本；
远端复制到手机原本已由 `onRemoteClipboardChanged` 自动处理。图片剪贴板仍只支持
native 已实现的方向，未在 UI 暴露。

### 6. 外接键盘导致 Activity 重建

`MainActivity` 的 `configChanges` 补充 `keyboard|navigation`，插拔实体键盘时不再
重建界面、丢失终端页签状态（`AndroidManifest.xml`）。

## 二、安装包精简

| 指标 | 1.3.4 | 1.3.5 | 变化 |
|---|---:|---:|---:|
| APK 大小 | 22,683,421 B（21.6 MiB） | 6,213,040 B（5.9 MiB） | **-72.6%** |
| 未压缩 DEX | 42,328,704 B | 2,949,768 B | -93.0% |
| native `.so` | 11,076,616 B，APK 内不压缩 | 同尺寸，deflate 压缩后约 4.5 MB | 约 -59% |

措施（`app/build.gradle.kts`、`app/proguard-rules.pro`）：

1. 开启 R8：`isMinifyEnabled = true`、`isShrinkResources = true`；
2. 开启 `packaging.jniLibs.useLegacyPackaging = true`，`.so` 压缩进 APK，安装时解压；
3. 移除未使用的 `androidx.compose.ui:ui-tooling-preview`。

R8 保留规则及原因：

- `LibFreeRDP`、`LibFreeRDP$Listener`、`RdpSession`：native 侧用
  `FindClass` / `GetStaticMethodID` / `GetMethodID` 按名字查找回调和接口方法；
- `SshConfig`、`Prefs`、`Tab`、`Signature`：Gson 反射序列化，字段名就是 JSON key；
- 整个 `com.jcraft.jsch`：JSch 通过反射注册算法实现；
- `-dontwarn` 覆盖 JSch/OkHttp 在 Android 上不存在的可选依赖
  （JNA/Pageant、log4j2、Kerberos GSS、junixsocket、Conscrypt、BouncyCastle、OpenJSSE）。

已用 DEX 字符串表核对：全部 `On*` 静态回调、`Listener` 接口方法、`freerdp_*`
native 方法、`SshConfig` 字段均保留。

**代价**：首次安装需解压约 11 MB native 库，安装时间略增；运行时无差异。
R8 会生成 `app/build/outputs/mapping/release/mapping.txt`，以后分析崩溃堆栈需要它，
该文件不应公开到下载目录。

## 四、已知限制（本次未改）

1. **无真机测试**：RDP 手势、键盘、剪贴板、SSH 重连只做了代码审查和编译验证，
   建议在真机上回归：连接 Windows → 输入中英文 → 长按右键 → Ctrl+Alt+Del →
   双向剪贴板 → 断网重连。
2. **RDP 证书策略**：仍使用 `/cert:ignore` 以兼容自签名 RDP。公网环境存在中间人
   风险，后续可改为 TOFU 指纹确认（SSH 已有 KnownHosts）。
3. **RDP 无前台服务**：SSH 有 `SessionService`，RDP 退到后台仍可能被系统冻结。
4. **16 KB 页兼容**：预编译的 FreeRDP `.so` 段对齐为 4 KB，Android 15 的 16 KB
   页设备可能无法加载，需要重新编译 native 库，属于工具链层面工作。
5. **RDP 图片剪贴板**：native 有接口，UI 未提供发送入口。

## 六、1.3.6 追加：RDP 数字小键盘

用户反馈在 RDP 里输入 Windows 登录 PIN、纯数字密码时反复切系统输入法不方便，
因此增加一个贴底的数字小键盘：

- 工具栏新增小键盘按钮（`Dialpad` 图标），更多菜单也可显示/隐藏；
- 布局：`Esc / × -`、`7 8 9 +`、`4 5 6 +`、`1 2 3 Enter`、`0(宽) . ⌫`；
- 数字键发送主键盘 `VK_0-9`（0x30–0x39），小数点用 `VK_OEM_PERIOD`，
  Enter/退格用 `VK_RETURN`/`VK_BACK`，因此远端 NumLock 开或关都能直接输入 PIN；
  四则运算发送小键盘 VK（`VK_ADD/SUBTRACT/MULTIPLY/DIVIDE`）。按键走 RDP 键盘
  通道，不依赖 `RdpSurfaceView` 焦点，也不经过系统输入法；
- 打开小键盘时自动收起软键盘，点键盘按钮时自动收起小键盘，两者不重叠；
- 面板高度按屏幕高度自适应（<520dp 用紧凑尺寸），返回键先收起小键盘再退出会话；
- 按键有系统触感反馈，右上角可单独收起面板。

修改文件：`ui/RdpScreen.kt`（面板与工具栏入口）、`RdpActivity.kt`（开关、收起输入法、
发送键码）。
